# MAX Parser

Overview
---
MAX Parser is a program made to parse the files (pictures, audios etc.) from the Russian national messenger MAX by VK.

This is possible because MAX has no encryption and files are available via their permalink even without any autorizations (even if you try to open it from another device).

Instruction
---
1. Install all modules using the command `pip install -r requirements.txt` in your command shell (Windows Powershell, bash, zsh).
2. Run the program using the command `python maxparser.py`. The directory will be created automatically.
